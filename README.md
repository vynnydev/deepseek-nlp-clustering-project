Projeto final desenvolvido para a disciplina de NLP e Machine Learning, abordando clustering, redução de dimensionalidade e classificação de intenções.

## 📋 Conteúdo

O projeto está dividido em 4 questões principais:

### 1️⃣ Clustering e Análise de Métodos de Validação
- Implementação de KMeans com método do cotovelo e silhuette score
- Análise comparativa de métodos de determinação do número ótimo de clusters
- Visualização e interpretação de resultados

### 2️⃣ Redução de Dimensionalidade
- Análise teórica de PCA, t-SNE e UMAP
- Casos de uso e recomendações para cada técnica
- Comparação de vantagens e desvantagens

### 3️⃣ Prompt Engineering para DeepSeek
- Desenvolvimento de prompt estruturado para extração de dados
- Formatação JSON com validação de schema
- Integração com LLM para processamento de receitas

### 4️⃣ Classificação de Intenções com NLP
- Pipeline completo de normalização de texto
- Vetorização TF-IDF
- Classificação por similaridade de cosseno
- Sistema de detecção de intenções em português

## 📦 Instalação
```bash
# Clone o repositório
git clone https://github.com/seu-usuario/deepseek-nlp-clustering-project.git

# Entre no diretório
cd deepseek-nlp-clustering-project

# Instale as dependências
pip install -r requirements.txt
```

## 🎯 Como Executar
```bash
# Inicie o Jupyter Notebook
jupyter notebook GS.ipynb
```

Execute as células sequencialmente para reproduzir todos os resultados.

## 📊 Resultados Principais

- **Clustering**: Identificação de 12 clusters com análise comparativa entre método do cotovelo e silhouette score
- **NLP**: Sistema de classificação de intenções com acurácia superior a 90% em português
- **Prompt Engineering**: Template reutilizável para extração estruturada de dados com LLMs
